# VPN Decryptor Desktop (رمزگشا و تبدیل‌گر کانفیگ‌های VPN)

نرم‌افزار دسکتاپ سبک و بومی ویندوز ساخته‌شده با **Rust + Tauri v2** و رابط کاربری **فارسی (راست‌به‌چپ) با طراحی Material 3**.

## امکانات کلیدی
- رمزگشایی آفلاین و کامل فرمت‌های: `.npvt`، `.npvs`، `.npv4`، `.inpv`، `.dark`، `.hat`، `.nm`، `.slip`، `.ssc`، `.hc`، `.ehi`، `.bpf`، `.ovpn`، `.conf`، `.yaml`، `.json`، `.txt`، `.sub`، `.list`، `.zip`
- همگام‌سازی پوشه با پشتیبانی از زیرپوشه‌ها و دکمه **«بررسی مجدد فایل‌های جدید»**
- انتقال اختیاری فایل‌های پردازش‌شده به **سطل زباله ویندوز (Recycle Bin)** پس از رمزگشایی موفق
- افزودن تکی/چندتایی فایل‌ها و **Drag & Drop** (فایل، پوشه، ZIP)
- دریافت لینک‌های اشتراک (خط‌به‌خط) همراه با تشخیص خودکار پروکسی سیستم و متن به‌هم‌ریخته
- مخزن رمزهای ذخیره‌شده محلی و تست خودکار یکی‌یکی
- ماتریس خروجی ۳ سطحی:
  - محدوده: `Mix_All` و/یا `Per_Source`
  - فرمت: `Xray (.txt)`، `Xray Base64 (.txt)`، `Sing-box (.json)`، `Mihomo (.yaml)`، و فایل‌های کمکی (`SSH` / `OpenVPN` / `DNS`)
  - تفکیک: `all_*` و/یا پوشه `By_Protocol` برای هر پروتکل (پشتیبانی کامل از ۲۶ پروتکل)
